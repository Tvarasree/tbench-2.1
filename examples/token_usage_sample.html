Methodology

Totals are a LOWER BOUND: unmeasured attempts contribute 0 and are disproportionately the killed/timed-out (expensive) ones.

Coverage quality: full 8 · partial 0 · total only 0 · unmeasured 2.

Custom prices are supplied with the run and are not provider-verified. Input includes cache; cache-read and cache-write rates are applied separately when available. Missing telemetry contributes no tokens, so incomplete-coverage totals are lower bounds.

Metric definitions

Including failed retries divides all measured run usage by tasks solved at least once. Winning attempt only uses the first successful trial per solved task. Average successful trial includes every independently successful trial and excludes failed trials.
